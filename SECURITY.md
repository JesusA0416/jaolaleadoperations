# Security and privacy notice

JAOLA Lead Operations v0.1 is a **public static demonstration**. It does not provide authenticated user accounts, role-based authorization, encrypted central storage, verified backups, cross-device syncing, or a vetted production privacy program.

### DO NOT

- Enter real customer names, phone numbers, emails, financial data, or confidential business information into the demo.
- Upload customer records, secrets, API keys, passwords, or real exported CSVs into the GitHub repository.
- Present the demo as a secure CRM, WhatsApp integration, or production-ready paid service.

### BEFORE accepting real data

Use appropriate hosted infrastructure and conduct a privacy/security assessment covering access rights, tenant isolation, data minimization, consent, incident handling, retention/deletion, backup, and applicable law in the relevant country. Do not rely on GitHub Pages or client-side `localStorage` for business records.
